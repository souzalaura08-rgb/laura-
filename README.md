# 🎵 MusicHub

Um site simples de reprodução de músicas desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Player de música
- Playlist
- Interface simples
- Fácil personalização

## Estrutura

```
site-musica/
│── index.html
│── style.css
│── script.js
│── README.md
│── music/
│   ├── musica1.mp3
│   ├── musica2.mp3
│   └── musica3.mp3
```

## Como usar

1. Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/site-musica.git
```

2. Abra o arquivo `index.html` no navegador.

3. Adicione suas músicas na pasta `music/`.
